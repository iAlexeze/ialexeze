Open Source Project

Orkestra

The first declarative operator runtime for Kubernetes. Built from scratch over three years without a template. Shipped, proven in production, and open source.

v0.7.11 · Early Access

Operators are behaviors, not programs.

Every Kubernetes operator rebuilds the same infrastructure: informers, workqueues, leader election, RBAC, webhooks, status management. That infrastructure is not the reason the operator exists — it's the cost of entry.

Orkestra removes the cost. You declare what your operator does in a Katalog. The runtime handles everything else — reconciliation, drift correction, autoscaling, deletion protection, a live control center. No Go code required. Your CRD is enough.
